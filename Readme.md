
Genie Android

Genie – Simple and Professional Salary Calculation

Genie is an Android application designed for workers and employers.

Languages

* Swedish
* English
* Serbian

Main Features

* Hourly salary calculation (Timlön)
* Monthly salary calculation (Månadslön)
* Collective agreement salary calculation (Kollektivavtal)
* Employer and worker accounts
* Firebase authentication
* Employer-worker connections
* Salary information sharing
* Two-way messaging

Technology

* HTML
* CSS
* JavaScript
* Firebase
* Capacitor
* GitHub Actions

Project Goal

To create a standalone Android application for Google Play using the existing Genie web application and Firebase backend.
